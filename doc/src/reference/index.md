# Reference

The Reference describes the current accepted inputs. It is divided by owner:

- [`lito.toml`](lito-toml/index.md) is owned by the manifest schema and typed manifest parser.
- [Project configuration](config/index.md) is owned by the config schema and merge/mutation API.
- [Command line](cli/index.md) is owned by the typed CLI definition and its generated help.

Examples in the Guide may combine several inputs. The Reference is the authoritative location for
field names, value kinds, defaults, and conflicts.
